# Playable Spaces

3D spaces built from real products. Move anything, buy what you like.

By Anas Qureshi. Live at https://playablespaces.vercel.app

How it is built: `kit/README.md` (a new space is one config file in `rooms/`).

Local preview: `node serve.js`, then open http://localhost:8091. Plain static files, no build step; three.js r169 is vendored in `vendor/three` (MIT, see its LICENSE).
