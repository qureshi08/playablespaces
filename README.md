# Playable Room

Interactive 3D rooms in the browser, built from real products. Move the furniture, swap the materials, pull the sun across the sky.

By Anas Qureshi. Live at https://playableroom.vercel.app

Local preview: `node serve.js`, then open http://localhost:8091. Plain static files, no build step; three.js r169 is vendored in `vendor/three` (MIT, see its LICENSE).
